Автоматически нарезанные элементы из двух UI-листов GEO EMPIRE.

Структура:
- sheet_ru_1/ : элементы из первой картинки
- sheet_ru_2/ : элементы из второй картинки
- manifest_all.csv : общая таблица координат

Важно: это автоматическая нарезка по границам визуальных элементов. В большинстве случаев вырезки корректные, но некоторые элементы могут быть нарезаны чуть шире/уже, потому что исходные картинки были не многослойными исходниками, а цельными листами.
